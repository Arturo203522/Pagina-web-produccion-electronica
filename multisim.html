Proceso en Multisim

Introducción a Multisim: construcción de un circuito con compuertas lógicas a partir de una función booleana, simulación de diodos y uso de señales eléctricas.

Instalación de Multisim Función booleana Circuito lógico Simulación Diodos Generador de funciones Señales desde archivo

Multisim es un software de NI para el diseño y la simulación de circuitos electrónicos. Permite construir circuitos de forma virtual, analizar su funcionamiento y observar cómo se comportan las señales eléctricas sin armar físicamente el circuito.

Proceso paso a paso

En esta práctica exploramos las herramientas principales del programa: empezamos con una función de álgebra booleana representada con compuertas lógicas y después trabajamos con diodos, generadores de funciones y fuentes de señales externas.

Objetivo

Aprender a utilizar las herramientas básicas de Multisim para diseñar y simular circuitos electrónicos, comprender el funcionamiento de las compuertas lógicas y analizar diferentes señales eléctricas.

Interpretar la función booleana
  • La función a construir Antes de construir el primer circuito retomamos el álgebra booleana que vimos en Diseño Digital. El profesor eligió una función lógica para reproducirla en Multisim, la de la imagen. Tiene cuatro variables de entrada (A, B, C y D) y cada una puede valer 0 o 1.

Operaciones que aparecen en la función

AND (Y)Se representa con una multiplicación. Su salida es 1 solo cuando todas sus entradas son 1.
OR (O)Se representa con una suma. Su salida es 1 cuando al menos una de sus entradas es 1.
NOT (NO)Invierte el valor de una variable. Por ejemplo, si B = 1, entonces B = 0.
( ) y [ ]Paréntesis y corchetes: indican el orden en el que se resuelven las operaciones.

La función se analiza por partes

1Se calcula B·D con una compuerta AND.
2Se obtiene C + B·D con una compuerta OR.
3Se calcula A·B·(C + B·D) usando NOT y AND.
4Se calcula A·B usando NOT y AND.
5Los dos términos anteriores se suman con una compuerta OR.
6El resultado se multiplica por C con una compuerta AND para obtener la salida F.
Construir el circuito lógico
  • [ imagen pendiente ]
    Colocar las compuertas y las entradas Con la función interpretada, la representamos con compuertas lógicas. Primero buscamos y colocamos las compuertas AND, OR y NOT que hacen falta, y después las entradas digitales para las variables A, B, C y D.
  • [ imagen pendiente ]
    Conectar las compuertas Conectamos las compuertas siguiendo el orden de las operaciones de la expresión, de izquierda a derecha y resolviendo primero lo que está dentro de los paréntesis antes de pasar el resultado a la siguiente compuerta.
  • [ imagen pendiente ]
    Conectar el indicador de salida La última compuerta se conecta a un indicador lógico para ver el resultado. Antes de simular revisamos las conexiones para asegurarnos de que no quede ninguna entrada sin conectar.
Simular y comprobar la función
  • [ imagen pendiente ]
    Ejecutar la simulación Con el circuito construido, ejecutamos la simulación y cambiamos las entradas entre 0 y 1 para ver cómo cambia la salida. Para verificar bien una función de cuatro variables se prueban todas las combinaciones posibles: como cada variable tiene dos estados, son 24 = 16 combinaciones. La salida tiene que coincidir con el resultado esperado de la expresión; así comprobamos que las compuertas están bien conectadas y que el circuito sí representa la función.
Componentes electrónicos y diodos
  • [ imagen pendiente ]
    Circuito con un diodo También exploramos el comportamiento de un diodo. Un diodo deja pasar la corriente principalmente en una dirección cuando está polarizado directamente; si se invierte su orientación puede bloquear el paso de la corriente, según las condiciones del circuito. Al simular un circuito con diodo se ve cómo afecta a la señal de entrada y cómo cambia el resultado al modificar su orientación. Este comportamiento es la base de aplicaciones como la rectificación de señales eléctricas.
Generador de funciones
  • [ imagen pendiente ]
    Colocar y configurar el generador Multisim tiene un generador de funciones que produce señales eléctricas para usarlas como entrada de un circuito. Se coloca el instrumento en el espacio de trabajo, se hacen las conexiones y se abre su configuración para elegir el tipo de señal.
  • [ imagen pendiente ]
    Formas de onda Identificamos tres formas de onda principales: senoidal (variación continua y periódica), triangular (aumenta y disminuye de manera lineal) y cuadrada (alterna entre dos niveles de señal).
  • [ imagen pendiente ]
    Frecuencia y amplitud También se pueden modificar la frecuencia y la amplitud. La frecuencia determina cuántos ciclos ocurren por segundo, y la amplitud indica el nivel de la señal respecto a su referencia. Al ejecutar la simulación se observa la señal generada y cómo responde el circuito conectado a ella.
Importar señales desde un archivo
  • [ imagen pendiente ]
    Fuente con señal externa Otra herramienta que vimos es una fuente que usa una señal definida a partir de un archivo externo. Se coloca la fuente en el circuito, se abre su configuración y se selecciona el archivo con los datos de la señal; después se puede usar como entrada para estudiar el circuito.
  • [ imagen pendiente ]
    Para qué sirve Es muy útil cuando se trabaja con señales de sistemas reales, como señales cardíacas de sensores biomédicos, señales cerebrales de aplicaciones de investigación o señales eléctricas de motores y otros dispositivos. Por ejemplo, una señal cardíaca registrada antes se puede introducir en un circuito para ver cómo cambia al pasar por una etapa de acondicionamiento, sin volver a generarla con un sensor físico.

Conclusión

Multisim sirve para diseñar, analizar y comprobar circuitos antes de armarlos. Con él representamos una función booleana con compuertas, estudiamos un diodo y trabajamos con distintas señales. Estos conocimientos son la base para evaluar un circuito de forma virtual antes de fabricarlo en los proyectos de Producción Electrónica, además de ayudar a detectar errores de conexión y reducir las pruebas físicas.
